# Data contract

All paths are relative to a **package directory** passed as `--package`.

## Input artifacts

### `draft.md` (text)

Manuscript excerpt or full draft. Consumed by the ethics LLM skill.

### `section_map.json` (object)

Boolean (or truthy) flags for section presence.

```json
{
  "title": true,
  "abstract": true,
  "introduction": true,
  "methods": true,
  "results": true,
  "discussion": true,
  "references": true,
  "limitations": true,
  "data_availability": false,
  "funding": false,
  "conflicts": false
}
```

**Required keys for full credit:** `title`, `abstract`, `introduction`, `methods`, `results`, `discussion`, `references`.

### `claims.json` (array)

Quantitative / citation claims extracted from the draft.

```json
[
  {
    "id": "C1",
    "section": "Results",
    "claim_type": "sample_size",
    "text_span": "analytic sample included 142 patients",
    "value": "142",
    "unit": "patients",
    "group": "total"
  }
]
```

| Field | Notes |
|-------|--------|
| `claim_type` | `sample_size` · `rate` · `mean` · `or_ci` · `p_value` · `difference` · `citation` · `other` |
| `text_span` | Exact quote preferred |
| `value` / `unit` / `group` | Optional normalized fields |

### `table_values.json` (array)

```json
[
  {
    "id": "T1",
    "variable": "sample_size",
    "group": "total",
    "value": "148",
    "unit": "patients",
    "cell_ref": "Table 1 header Total (n=148)",
    "raw_span": "Total (n=148)"
  }
]
```

### `table_notes.json` (array)

```json
[
  {
    "id": "N2",
    "text": "The p-value for the adjusted readmission model is not reported in this table.",
    "contains_or_ci": false,
    "contains_p_value": false
  }
]
```

Used especially for the statistical-reporting penalty when the draft asserts a p-value the table says is absent.

### `consistency_issues.json` (array)

Precomputed auditor findings (from a human or an upstream agent).

```json
[
  {
    "issue_type": "number_mismatch",
    "severity": "critical",
    "confidence": "high",
    "draft_span": "analytic sample included 142 patients",
    "table_or_ref_span": "Total (n=148)",
    "explanation": "Sample size mismatch: draft n=142 vs table n=148",
    "suggested_fix": "Reconcile cohort pull and update draft or Table 1 to the same n."
  }
]
```

| `issue_type` (common) | Role |
|-----------------------|------|
| `number_mismatch` | Draft vs table numeric conflict |
| `unsupported_claim` | Claim not backed by table/notes |
| `citation_error` | Year/DOI/metadata conflict |
| `duplication` | Near-paraphrase repetition |
| `contradiction` | Qualitative conflict |

| `severity` | Scoring impact |
|------------|----------------|
| `critical` | Heavy claim–evidence penalty; can force `no-go` |
| `high` / `medium` / `low` | Graduated penalties |

If `severity` is omitted, the scorer infers from `issue_type` / explanation / confidence.

### `references.json` (array)

```json
[
  {
    "id": "R1",
    "label": "Smith 2019",
    "year": 2019,
    "doi": "missing",
    "cited": true,
    "year_match": true,
    "status": "incomplete metadata"
  }
]
```

### `meeting_actions.json` (array)

```json
[
  {
    "task": "Request author affiliations for ScholarOne",
    "owner": "UNASSIGNED",
    "deadline": null
  }
]
```

`owner` empty / `UNASSIGNED` → internal-consistency penalty + warning issue.

### Optional `ethics_compliance.json`

If present and `--skip-ethics-llm` is set, reused as-is. Otherwise regenerated by the LLM skill.

## Output artifacts

Written under `--output` (default: `<package>/outputs/`).

### `ethics_compliance.json`

```json
{
  "status": "assessed",
  "study_involves_human_subjects": true,
  "irb_status": "mentioned_unclear",
  "consent_status": "mentioned_unclear",
  "data_use_status": "unclear",
  "trial_registry_status": "missing",
  "evidence_spans": ["...exact quotes..."],
  "notes": ["..."],
  "confidence": 0.9,
  "llm_provider": "openai",
  "llm_model": "gpt-4o-mini"
}
```

Allowed status examples for IRB/consent-like fields:  
`approved` · `mentioned` · `mentioned_unclear` · `missing` · `not_applicable` · `unclear` · `clear` (data use) · `registered` (registry).

### `research_readiness_scorecard_v1.json`

Top-level fields:

| Field | Meaning |
|-------|---------|
| `overall_score` | 0–100 weighted score |
| `readiness` | Final band after floors |
| `readiness_band_raw` | Band from score alone |
| `band_floors.applied_notes` | Why the final band changed |
| `dimension_weights` | Active weights (`null` if ethics excluded) |
| `dimensions.*` | Per-dimension `score`, `weight`, `status`, `metrics`, `notes`, `evidence` |
| `issues` | Prioritized findings |
| `remediations` | Suggested actions |
| `ethics_compliance_summary` | Short ethics echo |
| `scorecard_version` | `"v1"` |

Dimension object shape:

```json
{
  "score": 48,
  "weight": 0.35,
  "status": "assessed",
  "metrics": {},
  "notes": [],
  "evidence": []
}
```

For ethics when `not_assessed`: `score` is `null` and the dimension is excluded from the overall average.
